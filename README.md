So I made on a Dev-board based on Rp-2040 with similar size contrain like Xiao-Rp2040 but with more avilable pins then Xiao. So I used the smallest size of resistors and capaciotrs . It has acces to a total of 21 GPI0 and 4 Analog . 6 Pins act as dual purpose. It holds an USB-C Type interference for communication and 3.3V Voltage regulator and Crystal ossilator , Flash Memory , boot Switch  and more 

## Features

- Based on RP-2040 Chip
- Has MCP1700x-330xxTT as Voltage Regualtor 
- Has W25Q16JVUXIQTR as Flash Memory
- Has 3 set of 7 connector pins  
- Has 2 set of 2 connecotr pins for GND and 3.3V
